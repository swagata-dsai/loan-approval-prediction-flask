# 🏦 Loan Approval Prediction System

## 🌟 Project Overview

The Loan Approval Prediction System is a Machine Learning web application that predicts loan approval status based on applicant information. It uses a Decision Tree Classifier and a Flask web interface.

## 🚀 Live Demo

**Website:** https://enlarged-pelican-alienate.ngrok-free.dev

> **Note:** The demo link works only while the Google Colab Flask server and ngrok tunnel are running. The link may become unavailable when the session ends.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Flask
* HTML/CSS
* Google Colab
* ngrok

## 🤖 Machine Learning Algorithm

**Decision Tree Classifier**

## ✨ Key Features

* Data preprocessing and missing-value handling
* Categorical feature encoding
* Machine Learning model training
* Model accuracy evaluation
* Interactive web-based input form
* Loan approval prediction

## 🔄 Project Workflow

1. Load and explore the loan dataset.
2. Clean and preprocess the data.
3. Split the data into training and testing sets.
4. Train the Decision Tree Classifier.
5. Evaluate model performance.
6. Integrate the trained model with Flask.
7. Generate predictions through the web interface.

## 📂 Project Files

* `Loan_Approval_Prediction_Using_ML_and_Flask.ipynb` — Model training and evaluation
* `app.py` — Flask web application
* `requirements.txt` — Python dependencies

## ⚙️ How to Run Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd loan-approval-prediction-flask
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
python app.py
```

### 4. Open in Your Browser

Visit: http://127.0.0.1:5000
